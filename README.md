I trained as a computer engineer and wrote software before I moved into marketing. I have been at Google since 2008, first on global app marketing in California and now in Dubai, where I lead product and marketing across the Middle East and Africa. I also lead Arabic language and products work at Google.

The projects here are nights and weekends work. Most start as a small tool I want for myself: a way to read my own data, a reason to bring old hardware back to life, or a quick way to find a seat I can book with miles.

## What I Build Around

- **Local first tools** - Apps that run on your own machine and keep your data there, from DNA files to bookmarks to photos.
- **New code for old Windows** - Small native apps and tools for Windows 98, 2000 and XP, written in plain C with no runtime.
- **Arabic and the region** - Tools and games set in Dubai, Riyadh and Amman, that work in Arabic as well as English.

## Retro and System Tools

🏁 **[RetroWinBench](https://github.com/njarrar/RetroWinBench)** - A benchmark for Windows 98 and XP PCs. It tests the CPU, RAM, disk and 3D card, gives one score against a year 2000 Pentium III, matches your PC to a year from 1997 to 2008, and lists which of 135 classic games it can run. One 64 KB exe.

📝 **[TinyCodeXP](https://github.com/njarrar/TinyCodeXP)** - A code editor for Windows XP in the style of VS Code. Plain Win32 C, built with Tiny C Compiler, shipped as one 192 KB exe.

🌀 **[neoFanSpeed](https://github.com/njarrar/neoFanSpeed)** - A temperature and fan speed monitor for Windows 98, 98SE, ME, 2000 and XP. One file, NEOFAN.EXE, runs on all of them.

📊 **[SystemPulse](https://github.com/njarrar/SystemPulse)** - A local only system monitor with a native app for macOS, Windows 11, Linux, ChromeOS, Windows XP and Windows 98 SE. CPU, memory, power, heat, GPU, storage, network and top apps, each with ten minutes of history.
